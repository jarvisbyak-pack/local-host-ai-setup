# Local Host AI Setup
Fresh local JARVIS build. This repository is separate from the Friday project.
## Current machine
- Windows x64
- Node 24.13
- Python 3.12 virtual environment
- Ollama with qwen3:1.7b and llama3.2
- Local voice dependencies installed
## UI
- Chat and voice views
- Careful and Autonomous visual faces
- Bright/Night presentation
- Local-only browser interface
## Core
FastAPI bridges the UI to the local Ollama service on 127.0.0.1:11434.
No n8n dependency is part of this project.
